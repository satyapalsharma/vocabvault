---

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in this project, please follow these steps to report it responsibly:

1. **Do NOT** open a public GitHub issue for the vulnerability.
2. **Email** the security team at **security@example.com** with the subject line: `[SECURITY] Vulnerability Report – <short description>`.
3. Include as much detail as possible:
   - A description of the vulnerability and its potential impact.
   - Steps to reproduce the issue.
   - Affected versions and components.
   - Any suggested fixes or mitigations.
4. Our security team will acknowledge receipt within **3 business days** and provide a timeline for investigation and resolution.
5. Please do not disclose the vulnerability publicly until it has been patched and a security advisory has been published.

Thank you for helping keep this project and its users safe.
